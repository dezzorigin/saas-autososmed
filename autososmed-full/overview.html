AutoSosmed — Gambaran Sistem

Untuk siapa: tim builder/founder (7 produk). Masalah: 21 post/hari (3 post × 7 produk) di TikTok, Instagram, Threads tidak bisa manual. Keputusan: automasi jalur browser (Playwright, session reuse) dengan web bersama di autososmed.pages.dev, worker di VM Dokploy.

Alur sistem

Tim susun campaign di web (media + caption + target produk)
→ API pecah jadi 21 job (caption diputar per produk)
→ Worker browser posting serial per akun sesuai jeda
→ Tiap job simpan screenshot + URL sebagai bukti + notif Discord

Pipeline (10 langkah)

cron → load_tenant → entitlement → auth_reuse → captcha_login_branch → fetch_content → normalize_dedupe → execute_browser_post → notify + evidence

Risiko (jujur)

Jalur browser rawan captcha/ban di volume 21 post/hari. Mitigasi: 1 profil per akun, serial + jeda, caption/media bervariasi, captcha = berhenti bukan retry brutal. Jika ada ban massal: turun ke 1 post/hari/akun selama 7 hari.
